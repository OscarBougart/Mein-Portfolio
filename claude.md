# CarbonElk — Portfolio & Brand Site

## Project
Personal portfolio and brand page for Oscar Bougart / CarbonElk.
Stack: HTML, CSS, Vanilla JS. No frameworks.

## Brand
- Name: CarbonElk
- Palette: Deep charcoal #070b0f, Electric blue #00aaff, Off-white #ddeeff
- Font: Rajdhani (headings), Space Mono (labels, captions)
- Tone: Clean, minimal, personal. Not corporate.

## Responsiveness — TOP PRIORITY
- Never use fixed pixels for layout — use rem, em, %, vw, vh, clamp()
- Every component must work on mobile, tablet and desktop
- Mobile first — build small screen first, scale up
- Use clamp() for font sizes: example clamp(16px, 3vw, 32px)
- Use CSS Grid and Flexbox for all layouts
- No horizontal scrolling ever

## Code Rules
- Keep CSS organized — layout, typography, colors, components
- No inline styles
- JS only when CSS can't do it
- Comment any non-obvious code
- Class names: lowercase, hyphenated (elk-card, nav-link)

## Content
- About: personal and story-driven, not CV-like

## Do Not
- Use pixels for layout or font sizes
- Add unnecessary animations
- Use external libraries unless asked
- Change the color palette without asking
