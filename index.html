über mich.

Ich bin Oscar Bougart — ein Full-Stack-Webentwickler, geboren in Mexiko, geprägt durch Jahre des Lebens und Arbeitens in London, New York und jetzt Deutschland. Diese Reise hat mir beigebracht, mich schnell anzupassen, Menschen zu verstehen und Dinge zu bauen, die in der echten Welt wirklich funktionieren.

Ich gehe an Entwicklung genauso heran wie an alles andere — mit Liebe zum Detail und dem Antrieb, es richtig zu machen. Ich baue Web- und Mobile-Erlebnisse, die sich intuitiv anfühlen, sauber aussehen und echte Probleme lösen. Technisch und kreativ zu gleichen Teilen.

Vor dem Code habe ich über ein Jahrzehnt in der Gastronomie verbracht — Bars geleitet, Teams geführt und mich um das Gasterlebnis gekümmert. Dieser Hintergrund hat mir etwas gegeben, das die meisten Entwickler nicht haben: Ich weiß, wie man unter Druck arbeitet, klar kommuniziert und den Nutzer an erste Stelle setzt.

Ich baue unter dem Namen CarbonElk — ein kleines Studio, ein großer Anspruch. Jedes Projekt beginnt bei null und wächst zu etwas, worauf ich stolz bin. Dieser Prozess — aus nichts etwas zu machen — ist es, was mich jeden Tag antreibt.

Webdesign · 2024

Starlit

Project Overview

Ein modernes, minimalistisches Website-Konzept für eine AI-Produktidee. Die Seite überzeugt durch klare Struktur, intuitive Navigation und einen dezent futuristischen Look — inspiriert von modernem SaaS-Design und nutzerzentrierter Ästhetik.

Ziel war es, komplexe technische Funktionen so zu präsentieren, dass sie sofort verständlich und ansprechend wirken — ohne die Eleganz des Designs zu opfern.

  • Responsive Single-Page Layout
  • Animierte Hero-Sektion
  • Komponentenbasierte Architektur
React · CSS · HTML · JavaScript

Web App · 2024

The SpiritStack

Project Overview

Eine farbenfrohe Website im Vintage-Stil, auf der Barkeeper und Cocktailliebhaber spielerisch neue Mischtechniken entdecken können. Das Design greift auf warme Erdtöne und Retro-Typografie zurück, um das Thema authentisch zu unterstreichen.

Inhalte werden über die Notion-API dynamisch geladen, was eine einfache Pflege ohne technisches Know-how ermöglicht. Leichte Animationen sorgen für ein lebendiges, einladendes Erlebnis.

  • Notion als Headless CMS
  • Dynamische Rezeptfilterung
  • Animationen mit CSS Transitions
React · Tailwind · JavaScript · Notion

Full Stack · 2024

Feast & Fizz

Project Overview

Eine vollständige Full-Stack-App für Cocktail- und Speiserezepte. Nutzer können nach Namen oder Zutaten suchen und erhalten sofort passende Ergebnisse — gespeist aus einer externen Rezept-API und einem eigenen Django-Backend.

Besonderes Augenmerk lag auf der Performance: Suchresultate werden gecacht, Anfragen debounced und die UI reagiert in Echtzeit — ohne merkliche Ladezeiten.

  • Django REST Framework Backend
  • Externe API-Integration
  • Debounced Echtzeit-Suche
React · Django · Tailwind · Vite · API

Mobile App · 2025

Dram

Project Overview

Eine schnelle, fokussierte Notiz-App für Barkeeper — gebaut um das Problem zu lösen, dass Cocktailideen hinter der Bar so schnell verschwinden, wie sie kommen. Dram macht das Festhalten von Rezepten so reibungslos wie möglich.

Rezepte lassen sich in Sekunden speichern: Zutaten, Mengen und Techniken — strukturiert, durchsuchbar und immer griffbereit. Kein Overhead, keine Ablenkung.

  • Schnellerfassung mit minimalem UI
  • Lokale Persistenz mit IndexedDB
  • Custom Hooks für Rezeptverwaltung
  • Typsichere Datenmodelle mit TypeScript
React · TypeScript · Vite · IndexedDB

Web App · 2025

Golden Hour

Project Overview

Eine App für Fotografen und Naturliebhaber, die genau wissen wollen, wann das Licht am schönsten ist. Golden Hour berechnet Goldene Stunde, Blaue Stunde, Sonnenauf- und -untergang sowie die Dämmerungsphasen für jeden Ort der Welt.

Standortbasiert, präzise und visuell klar — damit du nie wieder einen perfekten Sonnenuntergang verpasst. Die Zeitangaben passen sich automatisch an die lokale Zeitzone an.

  • Echtzeit-Berechnung via Solar API
  • Geolocation für automatischen Standort
  • Visuelle Tageszeitleiste
  • Unterstützung für Goldene Stunde, Blaue Stunde, Dämmerung
React · TypeScript · Geolocation API · Solar API
