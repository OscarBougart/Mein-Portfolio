Webdesign · 2024

Starlit

Project Overview

Ein modernes, minimalistisches Website-Konzept für eine AI-Produktidee. Die Seite überzeugt durch klare Struktur, intuitive Navigation und einen dezent futuristischen Look — inspiriert von modernem SaaS-Design und nutzerzentrierter Ästhetik.

Ziel war es, komplexe technische Funktionen so zu präsentieren, dass sie sofort verständlich und ansprechend wirken — ohne die Eleganz des Designs zu opfern.

  • Responsive Single-Page Layout
  • Animierte Hero-Sektion
  • Komponentenbasierte Architektur
React · CSS · HTML · JavaScript

Web App · 2024

The SpiritStack

Project Overview

Eine farbenfrohe Website im Vintage-Stil, auf der Barkeeper und Cocktailliebhaber spielerisch neue Mischtechniken entdecken können. Das Design greift auf warme Erdtöne und Retro-Typografie zurück, um das Thema authentisch zu unterstreichen.

Inhalte werden über die Notion-API dynamisch geladen, was eine einfache Pflege ohne technisches Know-how ermöglicht. Leichte Animationen sorgen für ein lebendiges, einladendes Erlebnis.

  • Notion als Headless CMS
  • Dynamische Rezeptfilterung
  • Animationen mit CSS Transitions
React · Tailwind · JavaScript · Notion

Full Stack · 2024

Feast & Fizz

Project Overview

Eine vollständige Full-Stack-App für Cocktail- und Speiserezepte. Nutzer können nach Namen oder Zutaten suchen und erhalten sofort passende Ergebnisse — gespeist aus einer externen Rezept-API und einem eigenen Django-Backend.

Besonderes Augenmerk lag auf der Performance: Suchresultate werden gecacht, Anfragen debounced und die UI reagiert in Echtzeit — ohne merkliche Ladezeiten.

  • Django REST Framework Backend
  • Externe API-Integration
  • Debounced Echtzeit-Suche
React · Django · Tailwind · Vite · API
